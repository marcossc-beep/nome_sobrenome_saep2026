Instalação
Instale com o npm:

npm i fastify


Exemplo Básico (Usando Callbacks)
Aqui está como importar o framework, instanciá-lo e criar sua primeira rota usando a sintaxe de ES Modules:


import Fastify from 'fastify'

const fastify = Fastify({
  logger: true
})

// Declara uma rota
fastify.get('/', function (request, reply) {
  reply.send({ hello: 'world' })
})

// Executa o servidor!
fastify.listen({ port: 3000 }, function (err, address) {
  if (err) {
    fastify.log.error(err)
    process.exit(1)
  }
  // O servidor agora está ouvindo em ${address}
})
Prefere usar Async/Await?
O Fastify suporta async/await nativamente. Esta é geralmente a forma mais limpa e moderna de escrever seu código:


import Fastify from 'fastify'

const fastify = Fastify({
  logger: true
})

// Rota usando async/await (basta retornar o objeto!)
fastify.get('/', async (request, reply) => {
  return { hello: 'world' }
})

/**
 * Executa o servidor!
 */
const start = async () => {
  try {
    await fastify.listen({ port: 3000 })
  } catch (err) {
    fastify.log.error(err)
    process.exit(1)
  }
}

Incrível, isso foi fácil!

Nota: Infelizmente, escrever uma aplicação complexa exige significativamente mais código do que este exemplo. Um problema clássico quando você está construindo uma nova aplicação é como gerenciar múltiplos arquivos, a inicialização assíncrona (bootstrapping) e a arquitetura geral do seu código. O Fastify oferece uma plataforma robusta que ajuda a resolver todos esses problemas e muito mais!

Nota sobre o Host (Acessibilidade na Rede)
Por padrão, os exemplos acima escutam apenas na interface local (127.0.0.1). Se você precisar que seu servidor seja acessível por outros dispositivos na mesma rede (ou dentro de um container Docker), mude o host para 0.0.0.0:


// Exemplo com async/await configurando o host
const start = async () => {
  try {
    await fastify.listen({ port: 3000, host: '0.0.0.0' })
  } catch (err) {
    fastify.log.error(err)
    process.exit(1)
  }
}

Exemplo Completo: Rotas com Params, Body e Status

import Fastify from 'fastify'

const fastify = Fastify({ logger: true })

// 1. Recebendo parâmetros na URL (Params) e alterando o Status Code
// Exemplo: GET http://localhost:3000/produtos/42
fastify.get('/produtos/:id', async (request, reply) => {
  const { id } = request.params // 'id' vem direto da rota ':id'

  // Simulação de busca
  if (id === '42') {
    return { id: 42, nome: 'Teclado Mecânico', preco: 299.90 }
  }

  // Se não encontrar, define o status 404 (Not Found) e envia uma mensagem
  return reply
    .code(404)
    .send({ erro: 'Produto não encontrado' })
})

// 2. Recebendo dados no corpo da requisição (Body) e retornando Status 211 ou 201
// Exemplo: POST http://localhost:3000/produtos
fastify.post('/produtos', async (request, reply) => {
  const { nome, preco } = request.body // Os dados enviados no JSON do cliente

  if (!nome || !preco) {
    // Bad Request: dados obrigatórios ausentes
    return reply
      .code(400)
      .send({ erro: 'Os campos "nome" e "preco" são obrigatórios.' })
  }

  // Simula a criação de um recurso com sucesso
  const novoProduto = { id: Math.floor(Math.random() * 100), nome, preco }

  // Retorna o Status 201 (Created) junto com o objeto criado
  return reply
    .code(201)
    .send(novoProduto)
})

// Inicialização do servidor
const start = async () => {
  try {
    await fastify.listen({ port: 3000, host: '0.0.0.0' })
  } catch (err) {
    fastify.log.error(err)
    process.exit(1)
  }
}

Entendendo a anatomia do Request e Reply

O Objeto request
request.params: Um objeto que contém as variáveis passadas diretamente na rota. Se você definiu /usuarios/:slug, o valor estará em request.params.slug. Todos os valores vêm inicialmente como string.

request.body: Contém o corpo da requisição. O Fastify já faz o parse automático de requisições application/json por padrão, transformando-o em um objeto JavaScript pronto para uso.

O Objeto reply
No Fastify, quando usamos funções async, você pode simplesmente dar um return no objeto que o framework se encarrega de enviar com o status 200 OK.

No entanto, para mudar o comportamento padrão, usamos o encadeamento de métodos do reply:

.code(numero): Define o status HTTP da resposta (ex: 201 para criado, 400 para erro do cliente, 404 para não encontrado). Nota: O Fastify também aceita o codinome .status(numero), mas .code() é o padrão idiomático da ferramenta.

.send(dados): Envia os dados de volta para o cliente. Quando você chama .send(), você está finalizando a resposta.

💡 Regra de Ouro com Async/Await: > Se você alterar o status com reply.code(), lembre-se de terminar a execução retornando a resposta:
return reply.code(400).send(...)
